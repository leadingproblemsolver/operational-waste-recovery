# Operating Principles

1. Preserve source event identity and provenance.
2. Reject inconsistent token accounting.
3. Keep strict ingestion atomic.
4. Treat duplicate cost as potentially avoidable, not automatically recoverable.
5. Reject obvious credentials by default and make redaction explicit.
6. Keep mutation in the CLI; expose only read-only HTTP endpoints.
7. Bound files, lines, query text, result volume, and destructive actions.
8. Prefer inspectable SQLite/JSON/CSV/Markdown over infrastructure novelty.
9. Do not claim ROI, productivity, or organizational improvement without external evidence.
